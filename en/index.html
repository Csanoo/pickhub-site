Workloads

The right server depends on what you plan to run.

With the same budget, a different purpose puts the money in a different place. A consultation starts by finding which of these four is closest to yours.

Internal document search · Work chatbots

An LLM service that answers from your own documents. It is mostly inference rather than training, and is often kept on an internal network for security.

Check first · GPU memory, concurrent users

Video · Image analysis

Reads camera feeds or inspection images in real time. It runs around the clock, so stability and power efficiency matter most.

Check first · Number of streams, response time

Model training · Fine-tuning

Runs many GPUs together for long periods. Storage speed, node interconnect, and cooling shape the result as much as the GPUs do.

Check first · Data volume, training cadence

On-site · Edge AI

Installed outside a server room, in a factory or a store. Size, noise, and temperature limits are decided before performance.

Check first · Space, power, connectivity

Before you build

Is a workstation enough, or do you need a server?

A rack server is not always the answer. We sort the case by the criteria below first, and propose only what is needed.

CriterionGPU workstationGPU server
LocationBeside a desk in an office or labA rack in a server room or data centre
UsageUsed directly by one person or a small teamShared by many users, running 24 hours a day
GPUsOne or two, for development and experimentsSeveral per machine, scaled by adding nodes
Power · CoolingStandard outlets and room air conditioningDedicated electrical capacity and cooling
OperationsManaged by the userNeeds a scheduler, monitoring, and account policies
